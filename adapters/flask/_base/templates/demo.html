Soft Code Principles

This program is built to keep software changeable and scalable.

Decisions vs. Plumbing
Core logic stays pure. IO lives at the edges.
Plain Data Boundaries

Tests First

Dumb Orchestrator
Sequential flow, no embedded logic.
Side Effects at Edges
Adapters handle IO and frameworks.
Adapters Last
Build core first. UI and IO come after.
Add Files, Don’t Grow Them
Scale by adding modules, not bloating files.
Contracts Before Code
Define inputs and outputs before implementation.
